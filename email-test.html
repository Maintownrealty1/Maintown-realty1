Email test

Use this page to check that MainTown emails really arrive. Each test shows the exact answer from the server, so a failure explains itself.

1. Verification code (the app registration code)

Sends a real 6-digit code, the same one the app uses. Check your inbox and spam folder.

Not run yet.

2. Notification email (booking, inspection, payout style)

Sends a sample notification to the email of the account you are signed in with. Checking sign-in…

Not run yet.

3. Login emails sent by Supabase (password reset)

Sends a password-reset email, which uses the SMTP settings in Supabase Authentication. If this one arrives, your sender setup works for sign-in emails.

Not run yet.

4. Staff temporary-login email

Sends a sample “Your MainTown team login” email (with a dummy password) to the account you are signed in with. This is the same email a landlord's team member receives when you create their login. If it arrives, staff login emails are working.

Not run yet.

Common answers: 404 = the function is not deployed yet. 401 = deploy email-otp with “Verify JWT” turned off. 500 with a detail = the sender login or sender address is not accepted by the email service.
